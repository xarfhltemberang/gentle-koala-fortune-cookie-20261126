# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, written by `main.py` to `/output/entry.txt`.

## The entry

> Write the comment your future self needs at 2 a.m., for that tired stranger is you.

83 characters, one line, no trailing newline.

Why this line: it reads like a real fortune cookie — one short, balanced sentence that lands in a single breath — and it says something true about a developer's day: the 2 a.m. debugging session, and the comment you wish someone had left. The twist rewards a second read: the tired stranger you are writing the comment for is your own future self.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (Python 3 standard library only, no dependencies).
